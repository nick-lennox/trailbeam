- **A queue in another AWS account than the server's credentials no longer shows a same-named queue's CloudWatch
  figures** (QV-741). CloudWatch's SQS metrics name a queue only by its name, in the account that asks. When the
  AWS account ID in Settings was not the credentials' own (credentials reading another account's queues through a
  queue policy), the queue page and the dashboards showed the depth history, oldest-message age and dead-letter
  queue depth of the credentials' account's queue with the same name, next to the right SQS counts. Now such a
  queue shows its SQS settings and counts, no CloudWatch figures, and a sentence saying why. With an account ID
  set, the server now also calls `sts:GetCallerIdentity` (no permission needed) to learn the credentials' account.
