- **An S3 upload's reached list is complete in a busy bucket on SQLite** (QV-563). Before, the SQLite store looked
  up the bucket's notifications in the upload's time window, at most 2,000, and only then compared the object key.
  With more of the bucket's notifications than that in the window, an upload's reached list could come back short
  or empty, without saying it was cut, even on the page of a message it reached. Postgres was not affected. SQLite
  schema 25 adds the table `s3_receives`, one row per S3 notification receive with its key decoded, and drops the
  index `spans_receive_s3`; the upgrade runs on start and reads only the stored S3 receives.
