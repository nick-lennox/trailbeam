- **A missed read no longer sends an alert twice, and a deleted firing alert says so** (QV-660). A dashboard rule
  whose figure is missing at a check (a failed read of the queue figures, a queue with no data for a moment) keeps
  its alert state for up to 30 minutes, so when the figure comes back still past its limit it is the same incident
  and nothing is sent again. A firing dashboard rule whose widget or dashboard is deleted, or that has had no figure
  for 30 minutes, now sends one "No longer checked" change (`kind` "resolved", with `no_longer_checked: true` in the
  webhook body) instead of showing as firing for good. Every webhook change now carries `no_longer_checked`. Deleting
  an "Alert me" rule still sends nothing.
