- **Invites and password resets by email** (QV-587). With a mail server set up (`TRAILBEAM_SMTP_HOST`,
  `TRAILBEAM_SMTP_FROM` and, if it needs them, `TRAILBEAM_SMTP_PORT`, `TRAILBEAM_SMTP_TLS`, `TRAILBEAM_SMTP_USER`
  and `TRAILBEAM_SMTP_PASSWORD_FILE`), adding a person on the People page, or making a new link for them, emails
  them the one-time link instead of showing it. Without one, the page shows the link as before, and it also does
  when sending fails, with the reason. Links start with `TRAILBEAM_PUBLIC_URL` when it is set. The API's
  `POST /api/users` and `POST /api/users/{id}/link` take `"send_email"` and answer with `email`.
