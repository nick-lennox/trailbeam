- **A dashboard's queue table no longer takes most of a minute on a store with many queues** (QV-713). One
  queue table with every column, on a store that had seen 500 queues, took 44 seconds to answer: each row read
  every event once per column, and the 5-second limit on a measures answer was looked at only between widgets.
  Now a queue table or status grid reads the events once, shows at most the 200 busiest queues, and stops adding
  rows once the answer has taken 5 seconds, on the one-widget route too. `queuesTotal` counts the queues and
  `queuesCapped` says when some are left out. The same table now answers in about 0.01 seconds.
