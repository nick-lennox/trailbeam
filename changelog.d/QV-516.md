section: Fixed
---

- **The Python package no longer accepts an ID, ARN or account that ends in a newline** (QV-516). Its checks used
  `$`, which in Python also matches just before a final newline, so an SNS `MessageId` of `"abc\n"` or an
  EventBridge `account` of `"111122223333\n"` was exported on the receive. Node.js and the server reject these, so
  the server could not join such a receive. The SNS, EventBridge, S3 notification, PutEvents, publish ID,
  offloaded-size, redact-key and S3 bucket checks now match the whole value. New contract vectors cover the cases.
