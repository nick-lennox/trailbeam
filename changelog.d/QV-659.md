- **An "every" Alert me rule sends at every check that finds new messages** (QV-659, `@trailbeam/ui` 0.1.0-dev.22
  for the shared cases). When new messages reached the cause at several checks in a row, only the first check sent
  "New messages"; the others were recorded as still firing and sent nothing until a check with none new sent
  "No new messages". Now each of those checks sends "New messages" with that check's count, and the first check
  with none new still sends "No new messages". "Quiet" rules are unchanged. The shared alert cases
  (`alerts-parity.json`) hold both engines to it.
