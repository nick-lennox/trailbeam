section: Fixed

- **`trailbeam` stops on SIGTERM every time** (QV-502). A SIGTERM (`docker stop`, `systemctl stop`) that arrived
  while Python was running a garbage-collector callback was dropped, with "Exception ignored ... KeyboardInterrupt"
  on stderr. The server went on serving, and `docker stop` killed it after its timeout instead of letting it close
  the SQLite file cleanly. The handler now asks the server to stop rather than raising an exception, so the signal
  can't be lost.
