- **A message Trailbeam saw sent no longer shows "Arrived via SNS"** (QV-514; contract section 21.5). A receive whose
  body looked like an SNS envelope got an observed "Arrived via SNS topic" step even when a recorded `trailbeam send`
  had put the message on the queue, so anyone who could send to the queue could make the timeline say SNS delivered
  a message it did not. Such a message now gets no SNS arrival step, as the inferred EventBridge and S3 steps already
  worked (section 23.3). A publish joined through the envelope is still shown.
