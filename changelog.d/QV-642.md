- **Alerts JSON API in the server** (QV-642, internal until alerts ship in QV-592): `/api/alerts/rules`,
  `/api/alerts/channels` and `/api/alerts/state` list, make, change, mute or snooze and delete "Alert me" rules,
  add, change, remove and test alert channels (webhook, Slack, email), and show each rule's alert state and the last
  check. Forms are checked as in the hosted app, with its error texts, held to shared cases in
  `contract/fixtures/alerts-api.json`. Anyone who may read the API reads alerts and manages rules; only an admin
  manages channels once the server has accounts. A channel's target and a webhook's signing secret are never
  answered after it is added (lists show a Slack URL up to its team and a webhook up to its host). The routes answer
  only while `TRAILBEAM_ALERT_CHECK` is on, and keep what is made in memory until the alert tables come.
