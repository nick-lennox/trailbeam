- **Signed in with the shared token, the Account, People and Tokens pages say how personal accounts are turned on**
  (QV-767). On the README team install (`TRAILBEAM_TOKEN`, users and roles off), `/account` showed "Loading" for
  ever; it now says the browser is signed in with the server's shared access token and that personal accounts are a
  preview, off on this server. `/people` (403) and `/tokens` advised `trailbeam users create`, which refuses without
  `--accounts` and makes an admin the server ignores; they now say to start the server with `TRAILBEAM_ACCOUNTS=1`
  first, then run `trailbeam users create --accounts --email <email> --role admin`. `/api/me`'s `features` gains
  `accounts`: whether users and roles are on.
