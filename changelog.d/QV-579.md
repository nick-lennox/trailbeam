- **What is in a queue now, from spans** (QV-579). `GET /api/queues/{queue}/now` lists the messages your services
  sent or received that are in the queue right now, each visible or in flight, with how long its visibility timeout
  has left. It also lists the messages at `max_receive_count` that SQS will move to the dead-letter queue on the next
  receive attempt, what was deleted in the past minute and the moves to the dead-letter queue in the past hour. It
  makes no AWS calls: it lists only instrumented messages, and without the queue's settings it uses SQS's default
  visibility timeout of 30 s unless a ChangeMessageVisibility set another. The answer has the same shape as the
  hosted app's "In ‹queue› now", so the shared Overview can draw either.
