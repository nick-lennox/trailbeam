section: Changed
---

- **Upgrading: a body capture list with `*` now captures S3 object keys too** (QV-566). From this version a
  package treats a bucket as captured when its name, or `*`, is in the body capture list (QV-511). So an existing
  `TRAILBEAM_CAPTURE_BODY_QUEUES=*`, or a queue named like a bucket, starts exporting the object key of every
  `PutObject`, `CompleteMultipartUpload` and `CopyObject` as soon as you upgrade. Python's
  `trailbeam.boto.install()` hooks every boto3 `s3` client, with no option to leave S3 out; Node.js hooks only an
  `S3Client` you pass to `instrument`. The server stores a key only for a bucket that `TRAILBEAM_STORE_BODIES`
  names, or for every bucket when it is `*` (QV-564). Object keys often hold user IDs or file names. To keep them
  out, list queues by name instead of `*`, in the package and on the server, and keep bucket names out of both
  lists.
