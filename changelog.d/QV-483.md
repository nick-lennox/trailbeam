- **Over HTTPS, a cookie whose name only starts with an odd byte no longer counts as the session cookie** (QV-483).
  Since QV-473 the server trimmed cookie names with everything Python counts as whitespace, so a name such as
  `\xa0__Host-trailbeam_sid`, which a sibling subdomain or the plain-HTTP host can plant because the browser applies
  the `__Host-` rules only to names starting with `__Host-`, was read as the protected cookie (login CSRF, as in
  QV-408). Now only a space or a tab around a cookie name or value is trimmed.
