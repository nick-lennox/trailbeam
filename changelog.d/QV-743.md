- **The Overview reads CloudWatch for its queues together, and a person's new CloudWatch reads are capped** (QV-743).
  The Overview asked `/api/queues/{queue}/now` once for each queue, so with AWS reads on, each queue was its own
  `GetMetricData` every minute. It now asks the new `GET /api/queues/now?keys=` for up to 50 queues at once. The
  server reads a region's queues in one call, kept a minute for every viewer, and reads only the 3 metrics the
  Overview's health uses (and the dead-letter queue's depth) instead of 5. Each person may also have at most 3,000
  CloudWatch metrics a minute read that the server had not kept, so asking `/series` for range after range no
  longer adds to the AWS bill without limit. The README's "AWS reads" section says what reads cost.
