- **The Messages list at `/` is built from the Event explorer's parts** (QV-582, `@trailbeam/ui` 0.1.0-dev.27). It is
  in the app frame with the explorer's query bar, results bar, column list and rows. Filter with `queue:`, `tenant:`,
  `version:` and the body search (`body:<text>`, `body.<path>:<value>`) in one line, and press Enter; a term the list
  can't take is named before anything is asked, and a message ID typed alone opens that message. The range is the
  explorer's time picker, with Any time first (what the list showed before), and is in the link with Copy link and
  Live. Columns lets you hide columns and Export writes the page as CSV. A row has the explorer's bar on its left edge:
  red in a dead-letter queue, amber when received more than once. Before, the list had its own form and table in the
  old header frame. Links from the old list (`range=24h`, `from_ms` and `to_ms`, `body=` with plain text,
  `since_s`) still open what they named.
