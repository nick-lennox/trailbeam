- **Sign in with GitHub** (QV-664). With `--github-client-id`, `--github-client-secret-file` and `--public-url`, the
  sign-in page shows **Sign in with GitHub** beside the password form and single sign-on. It is GitHub's OAuth
  sign-in (github.com or GitHub Enterprise Server with `--github-url`), with its own settings: who may sign in
  (`--github-allowed-orgs`), who is an admin or a member (`--github-admin-teams`, `--github-member-teams`, as
  `org/team-slug`), `--github-default-role`, `--github-link-email` and `--github-session-hours`. Because anyone can
  make a GitHub account, the server refuses to start with it open to every account unless
  `--github-default-role member` says so. The account is the GitHub user ID, and the primary email must be verified
  at GitHub. No extra package is needed. See "Sign in with GitHub" in the README.
