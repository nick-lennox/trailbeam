- **The server's body opt-in covers S3 object keys** (QV-564). `TRAILBEAM_STORE_BODIES` now gates
  `trailbeam.s3.object_key` as it gates a body: a receive's key is stored only for a queue in the list, an
  upload's only for a bucket in it, and an S3 upload joins its receives only when the server names both. Before,
  the server stored every object key a package sent (SQLite `spans`, Postgres `s3_uploads` and `s3_receives`),
  whatever the list said. Keys stored before this version stay until retention drops them.
