- **Running the server from a clone** (QV-769). Without the web screen's build, `/overview`, `/events`,
  `/dashboards`, `/alerts`, `/settings`, `/queues` and `/queue` now say, as `/people` does, that the page is part
  of the build, how to build it and where its data is in the API, instead of a bare 404. `trailbeam start` warns
  when the web screen isn't built, and when the installed `trailbeam` library is 0.4.0 or older and still carries
  its own server and web screen, which `pip install ./server` alone fetches from PyPI. The README and
  `server/README.md` say to install `./python` and `./server` together, after `npm run build` in `ui/`.
