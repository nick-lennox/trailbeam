section: Changed
---

- **Dashboards and Alerts are documented, and the team install can turn them on** (QV-770). The README has a
  section for each: what it is, the switch (`TRAILBEAM_DASHBOARDS`, `TRAILBEAM_ALERT_CHECK`), and for alerts the
  channels, `--public-url`, the mail server and `TRAILBEAM_ALERT_ALLOW_PRIVATE_WEBHOOKS`. Both stay a preview in
  0.5, off by default. `.env.example` has a line for each of these settings and `docker-compose.yaml` passes them
  to the server; before, a team install could not turn either page on from `.env`. `contract/openapi.yaml` has the
  `/api/alerts` routes under a new Alerts tag (rules, mute, channels, test, state), and every answer the alert
  tests produce is now checked against it.
