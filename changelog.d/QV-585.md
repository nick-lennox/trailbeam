- **The Tenants page has the hosted app's design** (QV-585). It is the first open-source page in the new frame: the
  sidebar, dark by default with a light toggle, and a top bar whose one search box opens a message by its ID or
  lists a tenant's messages (`tenant:acme`), suggesting tenants from `/api/tenants/search` as you type. The table,
  the three ranges, the footnote, the README link and the `/api/tenants` link are as before; how many first
  deliveries a p95 is over is now a hover note on the p95 itself, and a tenant with no first delivery shows "none".
  The hosted app draws the same page from `@trailbeam/ui`.
