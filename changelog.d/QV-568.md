section: Changed
---

- **The server and the web UI are now AGPL-3.0-only; the libraries stay Apache 2.0** (QV-568). From 0.5.0,
  `trailbeam-server` (the server, its API and the `trailbeam` command), the container image
  `ghcr.io/nick-lennox/trailbeam` and the web UI (`@trailbeam/ui`) are under the GNU Affero General Public License
  v3.0 only. The client libraries (`trailbeam` on PyPI and npm, and the Java, .NET and Go libraries), the span
  contract, the conformance kit, the examples, the demo, the Helm chart and the Compose file stay Apache 2.0.
  Releases 0.3.0 and 0.4.0 stay Apache 2.0, and you can keep using them under it.
  - If you install a library in your service, nothing changes: the libraries contain no server code, and CI fails a
    change that makes one import it.
  - If you run the server, unchanged or with your own configuration, nothing changes either.
  - If you modify the server or the UI and let other people use your version over a network, the AGPL asks you to
    offer them its source code. If you can't do that, ask us for a commercial licence.
  - Why: everything in Trailbeam is open source, including dashboards and alerts, and the hosted service runs the
    same server. The AGPL keeps the server open: a company that offers a modified Trailbeam as a service has to share
    its changes too. The libraries stay Apache 2.0 so that adding one to your service never raises a licence
    question.
  - [LICENSING.md](LICENSING.md) says which folder is under which licence. Each package carries its own `LICENSE`,
    and the root `LICENSE` is now the AGPL-3.0 text.
