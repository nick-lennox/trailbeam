---
section: Changed
---

- **A personal API token can't create another one** (QV-759). `POST /api/me/tokens` with a personal API token is
  now `403`, `reason` `needs_a_session`. Before, a short-lived token (a 1-day CI token, say) could create one that
  never expires, and that one kept working after the first was revoked. Create tokens from the Tokens page, signed
  in in a browser or through the proxy. Listing and revoking your tokens still work with a token.
