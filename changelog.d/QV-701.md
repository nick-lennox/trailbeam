- **A note with half an emoji is refused with the usual message in both products** (QV-701). A note holding a
  lone surrogate (half of a UTF-16 pair, as a cut-off emoji leaves, which a script can send as `"\ud83d"` in
  JSON) made the self-hosted check raise an error instead of answering, and neither database could have stored
  it. The hosted rules let it through, and Postgres would have kept U+FFFD in its place. Both now give the
  "hidden characters" message, and the shared parity cases cover lone high and low surrogates and a whole pair,
  which still counts as 2 characters.
