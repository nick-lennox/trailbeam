- **SNS fan-out: messages that came through an SNS topic get their sender** (QV-313, contract revision 3.4, section 21;
  the Java jar does not hook SNS yet). The Python and Node.js packages record SNS `Publish` and `PublishBatch` to a
  topic as a `trailbeam publish` span (`trailbeam.kind = sns.publish`) with the SNS message ID and
  `aws.sns.topic.arn`. Receives carry what joins them to it: the `trailbeam.publish_id` message attribute the publish
  hooks add (raw delivery on; skipped when the message already has 10 attributes, would pass 256 KiB or uses
  `MessageStructure: json`; `TRAILBEAM_SNS_INJECT=off` turns it off), and, with raw delivery off, three fields of the
  SNS envelope: `MessageId`, `TopicArn` and `Timestamp`. These three are read on every queue, including queues whose
  body is not captured. Nothing else in the body is read, and the body is never exported. Node.js: pass an `SNSClient`
  to `instrument`. The server stores publishes apart from messages (SQLite schema 19: three partial indexes, built
  from one scan of `spans`; Postgres schema 13: `sns_publishes` and `sns_receives`) and joins them when a message is
  read: its timeline gets a `published` step with the SQS messages the publish reached, by queue, and the SNS delivery
  time (`SentTimestamp` minus the envelope's `Timestamp`, both AWS clocks). A message whose envelope names a topic but
  joins no recorded publish gets `arrived_via_sns`, placed before that receive. `/api/stats` counts `spans.publish`. A
  server before 3.4 rejects the publish span as an unknown kind (one rejected span in `partial_success`) and stores
  the rest. Both local UIs (the server's pages and `@trailbeam/ui`) show the "Published to topic" step with the
  publisher, how it joined, the SNS delivery time and the other messages it reached (links), and the "Arrived via SNS
  topic" step, with no time, before its receive. `TimelineView` takes an optional `messageHref` for those links;
  `@trailbeam/ui/fixtures/sns-timelines.json` is what the server returns after a fan-out (`@trailbeam/ui`
  0.1.0-dev.8).
