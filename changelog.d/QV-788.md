- **A member is not told the server's AWS setup when a queue is not read** (QV-788). As `/api/health` does since
  QV-744, a queue page, `/api/queues/…/now` and the dashboards tell someone who isn't an admin only that AWS (or
  CloudWatch) is not read for the queue and that an admin sees why, instead of the regions the AWS settings allow,
  the account they name, the credentials' own account, or that boto3 or credentials are missing. A queue that is
  not read keeps only the account and region its own spans name. `POST /api/redrive/gates` answers `not_manager`
  to a member as soon as AWS is on, before the redrive list, the account or the region is checked.
