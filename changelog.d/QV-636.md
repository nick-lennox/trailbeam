- **Alert delivery in the server** (QV-636, internal until alerts ship in QV-592): `trailbeam.server.alert_delivery` sends an alert's changes to a signed JSON webhook, a Slack incoming webhook, or email over an SMTP server you configure (STARTTLS, TLS or a plain relay), with the hosted app's message texts and payload, held to them by shared cases in `contract/fixtures/alerts-delivery.json`. Standard library only; a 10-second deadline, no retries, no redirects followed, webhook hosts that resolve to private addresses refused, and no secret in logs. Nothing calls it yet.
