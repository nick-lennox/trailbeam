- **A webhook's address is checked before connecting** (QV-672, internal until alerts ship in QV-592). A webhook or
  Slack send now looks up the host itself and refuses it with one message, "The webhook's host is a private or local
  address.", if any address the name has is private. In that case it connects to nothing. The answer no longer
  depends on whether a port is open, closed or filtered, so a test send can't map the server's network. The
  connection then goes to the checked address, keeping the host name for the Host header and TLS, so DNS can't answer
  differently in between. The lookup now counts against the 10-second deadline, so a slow resolver can't stretch a
  send. A name that doesn't resolve reads "The endpoint could not be reached: its host name was not found."
