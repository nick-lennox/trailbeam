- **The sign-in pages load the design system's fonts** (QV-775). Sign in, Create your admin account, Choose your
  password and the other server-rendered sign-in pages were drawn in the browser's fallback serif and sans, because
  the font files are under /ui/, which needed sign-in. These pages now link the same Newsreader, Instrument Sans and
  IBM Plex Mono files as the rest of the web screen, and the server sends those font files (and only those) to anyone.
  Without the web screen's build, the system's fonts still stand in.
- **Sign in has the hosted sign-in's title and order** (QV-775). It says "Welcome back." and "Sign in to see your
  queues.", then the single sign-on, GitHub and passkey buttons, "or with your email", and the form. What went wrong
  (a wrong password, a locked account) shows above the Sign in button, as on hosted. The access token page has the
  same title.
