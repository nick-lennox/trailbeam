- **Broken characters in a dashboard or an alert are refused, not a server error** (QV-687). A lone half of an
  emoji ("\ud800", as cut-off pasted text leaves) anywhere in a dashboards or alerts API request (a name, a widget
  title, a key, or an imported definition) now gets a 400 that says to retype the pasted part. Before, the server
  could not store it and answered 500.
