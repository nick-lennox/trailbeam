# Notes for agents working in this repository

- Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
- **Changelog entries go in `changelog.d/QV-NNN.md`, never in `CHANGELOG.md`** (format:
  [changelog.d/README.md](changelog.d/README.md)). CI fails a pull request that adds a line under Unreleased in
  `CHANGELOG.md`. When you merge `main` into your branch, there is no changelog conflict to resolve any more.
